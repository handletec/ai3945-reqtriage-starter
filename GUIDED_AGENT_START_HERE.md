# AI3945 — Guided Agent Hands-On

After cloning this repository:

```bash
cd guided/simple-parcel-agent
```

Then read:

```text
README.md
```

This lab assumes you are a developer but not an agent specialist.

Use GitHub Copilot with Claude as your **coding assistant**. Claude helps you write the Python. The Python program you build is the actual agent.

Start with:

```bash
python check_env.py
```

Then follow `LAB.md` checkpoint by checkpoint.

Do not ask Copilot to finish the entire agent in one shot. Use the bounded prompts in the lab and run the code yourself after each step.
